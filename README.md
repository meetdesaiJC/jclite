# Agent Assist

Interactive prototype for JustCall AI Agent Assist — scripts, checklists, and the JustCall AI shell.

## Getting started

```bash
npm install
npm run dev
```

Opens the prototype at [http://localhost:5679](http://localhost:5679).

## Stack

- **React 19** + **TypeScript**
- **Tailwind CSS v4**
- Design System 2.0 components in `src/`
- Prototype app in `prototype-justcall-ai/`
